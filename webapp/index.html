使用说明 / 常见问题

1. 浏览器：需要 Chrome / Edge（桌面版或安卓版）。iPhone 的 Safari 不支持 Web Bluetooth。

2. 电脑蓝牙：Windows 需开启蓝牙并安装好适配器驱动；连接前不要先配对（由网页直接连接）。

3. 变量不出现：确认主控已通过串口发来变量声明；点“重新读取主控变量”会向主控请求重发。

4. 值被拉回：变量以主控为准，主控若周期性上报，会覆盖手机刚改的值——这是正常的同步行为。
